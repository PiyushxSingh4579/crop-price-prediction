About This Project

The Crop Price Predictor is a machine learning application that predicts the Modal Price (₹ per Quintal) of agricultural commodities across various markets in India.

Dataset

The model is trained on agricultural commodity price data from Indian markets, containing information about State, District, Market, Commodity, Variety, Grade, and their corresponding prices.

Methodology

  • Data Cleaning: Removed records with invalid prices (zero or negative)
  • Feature Engineering: Log-transformation applied to target variable to handle price skewness
  • Encoding: Target Encoding with 5-fold cross-fitting to handle high-cardinality categorical features without data leakage
  • Models Evaluated: Ridge Regression, Random Forest, Gradient Boosting, XGBoost, and LightGBM
